# 🅿️ ParkEase – Smart Parking System

ParkEase is a web-based smart parking management system built using **Flask**. It helps users reserve and release parking spots and provides admins with tools to manage lots and view real-time stats.

## 🚀 Features

### For Users
- Register/Login
- View & book available parking spots
- Release active bookings
- View parking history

### For Admins
- Manage parking lots and spots
- View all users and bookings
- Dashboard with revenue and occupancy charts

## ⚙️ Tech Stack
- Python, Flask, SQLAlchemy
- HTML, CSS, Jinja2
- SQLite (development DB)
- Matplotlib for charts
